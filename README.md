# Portfolio

Open `index.html` in a browser to preview (works offline except Google Fonts).

- `index.html` – main page: hero, education, projects, certificates, experience
- `style.css` – all colors, fonts and layout (variables at the top)
- `projects/*.html` – one page per project
- `images/hero.jpg` – the hero picture (replace it, keep the name)
- `images/projects/` – put project screenshots here

Hosting: push the folder to GitHub and enable GitHub Pages, or drag it into Netlify.
