Flags & Maps

C++Qt

About

A desktop geography quiz with two modes: guess the country by its flag or by its outline on a map. Each round shows a picture and four answers, and the player has one minute to get as many right as possible.

I built it in C++ with Qt Widgets. The quiz covers 118 flags and 85 country maps, and the best result in each mode is saved between games.

What it includes

  • Two modes, flags and maps, chosen in the start window
  • Four answer buttons with one correct country and three different random wrong ones
  • Instant feedback: the correct answer turns green and a wrong pick turns red
  • One-minute timer and a live score of correct answers out of all tries
  • End screen with the result and a new-record message
  • Best score for each mode saved to a file and shown in the start window
  • Windows designed in Qt Designer and connected with signals and slots
