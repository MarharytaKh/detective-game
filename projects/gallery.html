About

A web gallery for 3D models in GLB format. You upload a model with the plus tile, it appears in the gallery with a live preview, and you can open it in a viewer that is built for checking a model rather than just looking at it.

It was university coursework. The app runs as three Docker containers: a PostgreSQL database, a Node.js app, and an Nginx reverse proxy with hardened SSH access.

What it includes

  • Upload, delete, search and sort models by name, size or date, with favorites and notes
  • Viewer built with Three.js: orbit camera, a light you can rotate, and a background color that is remembered per model
  • Model stats: number of meshes, materials, vertices and triangles
  • Preview modes for texture checks: base color, normal map, ambient occlusion, roughness, metalness, UV checker and wireframe
  • REST API in Express with file uploads through Multer, and model records kept in PostgreSQL
  • Docker Compose setup with Postgres, Node.js and Nginx on an internal network
  • Server security: SSH with key-only login, Fail2ban against brute force, and an iptables firewall
